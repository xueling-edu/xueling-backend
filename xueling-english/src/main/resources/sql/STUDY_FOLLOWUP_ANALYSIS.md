# 评分后巩固内容与效果观测

## 内容审核

`word_study_content` 每词只维护一个本轮核心义。编辑内容时先保持 `approved=0`；核对核心义、英文例句、译文与题目都表达同一词义，两个选项含义不同，正确选项与线索解释一致后，更新 `content_version`、`reviewed_at` 并将 `approved` 设为 `1`。题目字段任一缺失时，前端只展示核心义讲解。词典原始例句不自动充当审核过的教学题。

每次首次评分创建的 `word_study_followup` 行保存 `request_id`、评分档位、内容版本和教学/回访结果时间。重写内容时应增加版本；已经开始的巩固任务会退回核心义讲解，而不会把新版选项混入旧版结果。评分日志和 FSRS 状态不受教学结果影响。

## 分析口径

- `word_review_record` 是正式英译中回忆。`due_before IS NULL` 表示新词首次评分；`due_before <= reviewed_at` 才是正式到期复习。
- `word_study_followup.teaching_result` 表示教学动作结果，`revisit_result` 表示本轮隔开后的回声结果。`revisit_pass` 不应当作长期保留率。
- 按首次评分的 `request_id` 连接 `word_study_followup`，再取**同一用户、同一单词、该次评分之后的第一条正式到期评分**，即可比较教学完成与未完成组的下一次回忆率。报告时按首次评分档位、新词/复习词、内容版本分层，同时展示样本数和未到期样本数。
- 操作负担可由评分的 `elapsed_ms`、教学和回访时间、未完成行、`skipped` 比例估计；前端停留时长和会话中途退出率尚需独立的匿名交互遥测，不能从现有表精确推断。

排程参数保持原值，收集真实样本后再评估 P3。
